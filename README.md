# FORMA — сайт персонального тренера

Адаптивный сайт в чёрно-красно-белой палитре с услугами, ценами, презентацией тренера, галереей, FAQ, формой записи и панелью администратора.

## Файлы

- `index.html` — публичный сайт и форма записи.
- `admin.html` — вход администратора, управление заявками и услугами.
- `supabase/schema.sql` — таблицы PostgreSQL и политики Row Level Security.
- `privacy.html` — базовая страница о конфиденциальности, которую нужно адаптировать под реальные процессы.

## Локальный запуск

Можно открыть `index.html` в браузере для просмотра дизайна. Чтобы форма записи и админ-панель работали с базой, подключите Supabase. Для локального запуска с корректными путями удобнее использовать VS Code Live Server или любой статический HTTP-сервер.

## Подключение Supabase

1. Создайте проект в [Supabase](https://supabase.com/).
2. Откройте **SQL Editor** в панели Supabase.
3. Скопируйте содержимое `supabase/schema.sql` и выполните его.
4. В **Project Settings → API** найдите Project URL и публичный ключ **anon / publishable**.
5. В начале JavaScript в файлах `index.html` и `admin.html` заполните:
   ```js
   const SUPABASE_URL = "https://YOUR-PROJECT.supabase.co";
   const SUPABASE_ANON_KEY = "YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY";
   ```
   Используйте только публичный anon/publishable key в браузере. **Никогда не вставляйте service_role/secret key в HTML или репозиторий.**
6. Создайте учётную запись администратора в **Authentication → Users**. Отключите публичную регистрацию, если она не нужна.
7. Скопируйте UUID созданного пользователя и выполните в SQL Editor, подставив настоящий UUID:
   ```sql
   insert into public.admin_users (user_id)
   values ('YOUR-AUTH-USER-UUID');
   ```
8. Откройте `admin.html` и войдите с учётными данными этой учётной записи.

После настройки публичная форма может только создавать новые заявки со статусом `new`. Посетители не имеют права читать заявки, менять их статус или удалять их. Просматривать и обрабатывать заявки могут только пользователи, добавленные в `admin_users`.

## Важные замечания

- Демонстрационные цены и текст в профиле необходимо заменить перед публикацией.
- Контакты в секции связи — примеры; укажите реальные адреса и ссылки.
- Отзывы намеренно не выдуманы. Добавляйте только настоящие отзывы с разрешения клиентов.
- Форма записи не отправляет уведомления по почте или Telegram: для уведомлений потребуется отдельная Edge Function/серверная функция и настройки секретов.
- Сайт не проверяет свободные интервалы в расписании. Запись считается заявкой и требует подтверждения тренером.
- Политика конфиденциальности должна соответствовать тому, какие данные вы собираете, где храните и каким образом обрабатываете.
- Фотографии загружаются со стороннего Unsplash для демонстрации. Замените их на изображения, которыми вправе пользоваться владелец сайта.
- Supabase Storage пока не интегрирован в интерфейс. Загрузка фотографий через админку — следующий этап; сейчас в услуге можно сохранить URL изображения.
- Сайт использует Supabase JS и шрифт Manrope с CDN, поэтому для полной загрузки этих ресурсов требуется интернет.

## Публикация

Для статической версии можно включить GitHub Pages в **Settings → Pages** и выбрать ветку `main`, каталог `/ (root)`. После подключения Supabase сайт можно публиковать как статический frontend, поскольку база и аутентификация обслуживаются Supabase. Не публикуйте реальные ключи или персональные данные в коммитах.
